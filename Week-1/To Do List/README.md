
# TaskFlow - To-Do List

A task management web application built with HTML, CSS, JavaScript, Node.js, Express, and MongoDB.

## Features

- Create, view, edit, and delete tasks
- Mark tasks as completed or pending
- Task categories and priorities
- Due dates and descriptions
- Search and filters
- Drag-and-drop between Active and Completed
- Dashboard statistics
- Light and dark theme

## Technologies

- HTML, CSS, JavaScript
- Node.js and Express.js
- MongoDB and Mongoose

## Setup

1. Install Node.js and MongoDB.
2. Clone this repository.
3. Install dependencies:

   ```bash
   npm install
   ```

4. Create a `.env` file.
5. Start the server:

   ```bash
   node server.js
   ```

6. Open http://localhost:3000

## Environment Variables

Configure `PORT` and `MONGO_URI` in your local `.env` file.
